# ХАУС-Х — сайт недвижимости

Статический сайт агентства недвижимости. Первая версия создаётся без серверной части и административной панели.

## Состав
- `index.html` — главная страница и разделы каталога, услуг, компании и контактов.
- `styles.css` — адаптивный визуальный стиль.
- `properties.js` — ручной каталог объектов.
- `app.js` — фильтры, сортировка, карточки и интерактивность.
- `privacy.html` — черновик политики конфиденциальности.

## Как добавить объект
Откройте `properties.js` и добавьте новый объект в массив `window.HOUSE_X_PROPERTIES`. У каждого объекта должен быть уникальный `id`. Заполните тип, заголовок, адрес, цену, площадь, изображение и описание.

## Локальный просмотр
Откройте `index.html` в браузере или запустите локальный сервер:
```bash
python -m http.server 8000
```
Затем откройте http://localhost:8000

## Перед публичным запуском
1. Заменить демонстрационные фотографии и данные объектов на реальные.
2. Указать действующие телефон, почту и реквизиты.
3. Утвердить политику конфиденциальности и согласие на обработку персональных данных.
4. Подключить серверную отправку заявок и Telegram-уведомления.
5. Добавить реальные метаданные, карту сайта и аналитику.
